Beginner questions include

The Structure

  1. What are you trying to do?
  2. What happened instead?
  3. What did you already try?
  4. What do you think is wrong?
  5. What help do you need right now?
‹15›
@Nerajno · #AskBetter
Before / After

The Difference

❌ WEAK

"My app is broken."

✅ STRONG

"Getting a 422 on form submit in my Vue app. Payload looks correct — confirmed in network tab. Tried validating each field. Can't tell which the server rejects. Help me narrow it down?"

‹16›
@Nerajno · #AskBetter
Years 1–3 upgrade

Name Your Hypothesis

"I think the bug is in the state update — the component renders fine before the async call returns. Moved the update to a separate function, same result. Timing problem?"

Shows reasoning, not frustration. Invites collaboration. Closes the loop after.

Speaker Backup — Core Notes

Arc: Asking is a skill that evolves. Early = clarity. Mid = judgment + timing. Senior = tradeoffs + leadership.

AI: GitHub Copilot, Claude, ChatGPT as first-line. Respects team time. Escalate when repo-specific, judgment-required, or high-stakes.

Rubber duck: Explaining the problem often solves it. When it doesn't, the explanation IS the question.

Psych safety: If asking feels unsafe on your team, that's a team culture problem. Name it.

Formula #6: "What will I do next" is the most underrated step. Signals maturity. Keeps the conversation moving.

Key quote: "The goal isn't to ask less. The goal is to ask better." — Progress over Perfection.
